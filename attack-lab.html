Attack Lab

This laboratory generates controlled security activity against the CyberGuard Test Server for defensive testing.

BRUTE FORCE TEST

Makes 5 real login attempts with random wrong passwords, one per second. Fixed target: this project's own authentication only.

Limitation: a browser cannot drive the Test Server's login page from another origin (same-origin policy), and this lab does not work around that. Instead it sends real login requests to the same Supabase Auth service and then calls the same log_failed_login() function the Test Server uses, but only after Auth rejects the attempt. Events are labelled source ATTACK_LAB.

Manual procedure (always works): 1. Open the Test Server. 2. Enter a wrong password 5 times. 3. Return here to the SOC Dashboard. 4. Watch the real events arrive.
