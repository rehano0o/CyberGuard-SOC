From security event to incident

CyberGuard SOC monitors real security events generated by the companion CyberGuard Test Server. It detects suspicious failed-login patterns, raises alerts, and provides a small analyst workflow for investigation.

CONTROLLED ATTACK LAB

The Attack Lab generates five real rejected authentication attempts against this project's own Supabase Auth service. The resulting events are labelled ATTACK_LAB so analysts can distinguish laboratory activity from normal Test Server activity.

⚠ Controlled environment only CyberGuard is an educational project designed for its own Test Server and Supabase project. It does not scan or attack arbitrary websites, IP addresses, or third-party systems.
